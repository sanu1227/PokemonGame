# PokemonGame 기획 자료

사용자가 확인한 참고 대상은 **예전에 즐긴 원작 드래곤빌리지이며, 컬렉션이 아닙니다.** 여기에 포켓몬의 요소를 결합하려는 프로젝트입니다. 현재 작업은 조사와 기획 구체화이며 게임 구현은 아직 시작하지 않았습니다.

구체적인 기획을 검토하려면 다음 두 문서부터 읽습니다.

1. [게임 구조와 첫 플레이 초안](docs/03_게임_구조와_첫_플레이.md) — 결합 방향 두 가지, 공통 게임 순환, 획득·육성·전투·탐험 규칙 후보, 예시 플레이와 보상·실패 처리.
2. [검증 범위와 의존성](docs/04_검증_범위와_의존성.md) — 작은 검증 범위, 진행 순서, 작업별 완료 조건, 위험과 축소 순서.

근거와 결정 기록은 기존 문서에서 이어서 관리합니다.

1. [레퍼런스 조사와 조합 아이디어](docs/01_레퍼런스_조사.md) — 작품별 사실, 핵심 순환 비교, 설계 선택의 장단점, 독자 콘셉트 후보.
2. [기획 결정 체크리스트](docs/02_기획_결정_체크리스트.md) — 먼저 답할 질문, 작은 검증 범위, 필요한 기획 산출물, 미정 사항 기록.

포켓몬에서 참고할 요소가 **포획·모험인지, 상성·커맨드 배틀인지, 둘 다인지**는 아직 답을 받지 않았습니다. 플랫폼·도구·인원·일정, 최종 획득·전투 방식도 미정입니다. 03의 예시 규칙은 검토할 수 있을 만큼 구체화한 가정이며 확정 사양이 아닙니다.

조사·갱신 기준일: 2026년 11월 4일. 현재 원작의 2024·2026년 기능 설명을 예전 버전의 규칙으로 소급하지 않습니다. 공식 사실, 사용자 확인 사항, 기획 제안을 구분하며 공식 이미지·음원은 포함하지 않습니다.
